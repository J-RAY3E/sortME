# Skill: description style

Every description must be in ENGLISH, regardless of the language of the source
title or URL.

Write three clearly separated parts: `problem`, `method` and `takeaway`. Each
part must contain at least two full sentences. The three parts joined together
should read as a coherent ~90-word paragraph.

Rules:
- Be concrete: name the technique, dataset, metric or claim actually present.
- Do not write marketing language ("amazing", "must-read", "game-changing").
- Do not invent results or numbers that are not implied by the title/URL.
- If the URL is a PDF with an opaque name, infer from the title only and stay
  cautious rather than fabricating specifics.
- Keep each string on a single line (no newline characters inside JSON strings).
